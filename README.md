One letter for your day — W, for a wobble of a day: unsteady legs, spilled coffee, bumping into doorframes. The program writes exactly one character, the letter W and nothing else, to `entry.txt`.

## Run it

```sh
node main.ts
```

This writes a single byte (`W`, no newline) to `./output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory.
